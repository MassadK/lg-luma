# Luma Liquid Glass

Independent native Rust/SDL2/OpenGL ES fork of [ecklf/lg-luma](https://github.com/ecklf/lg-luma), retaining its MIT license and asset attribution.

**0.1.0 · standalone application · no Home takeover**

Install `com.lumaglass.launcher_0.1.0_arm.ipk` alongside the original Luma. See [installation, build, rollback and verification](LIQUID_GLASS.md), [changelog](GLASS_CHANGELOG.md), and [native desktop screenshots](docs/liquid-glass).

Settings → Appearance → Interface Style selects Original Luma or Liquid Glass. In Liquid Glass, adjust Glass Transparency in 5% steps, or choose Crystal, Balanced or Frosted. Preferences persist independently of upstream Luma.

Actual LG C1 installation, remote navigation and firmware permissions require hardware verification. Desktop images are rendered by the native application using sample data.

`UPSTREAM_README.md` and `development.md` preserve upstream context. Their takeover, autostart and updater instructions do **not** apply to this fork. This release disables those operations.
